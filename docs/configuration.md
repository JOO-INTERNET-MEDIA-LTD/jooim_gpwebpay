# Configuration

Required values usually include:

- Merchant number,
- provider code,
- private key in PEM format,
- private key password,
- GP webpay public key,
- test or production mode,
- allowed currencies,
- order-state mapping.

The module includes a Joobox support panel above the settings form. It links to Joobox PrestaShop Cloud, where supported installation, configuration, production testing and updates are available.

A small Joobox footer attribution text in displayFooterAfter when available is shown in the shop footer. It is not configurable from the module settings. The template contains duplicate-output prevention so that multiple JOOIM modules do not print multiple Joobox attribution blocks.
