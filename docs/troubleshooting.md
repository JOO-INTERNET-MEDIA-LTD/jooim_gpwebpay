# Troubleshooting

Before opening a GitHub issue, check:

- PrestaShop version,
- PHP version,
- OpenSSL availability,
- cURL availability,
- correct Merchant number,
- correct provider code,
- correct private key and password,
- correct GP webpay public key,
- test/production mode,
- logs in the order detail and database tables created by the module.

Do not publish private keys, passwords, merchant credentials, customer data or production payment responses.

GitHub Issues are only for reproducible module bugs. Individual shop debugging is available only for Joobox PrestaShop Cloud customers.
